# 18-music / Music / 音乐与声乐成长

> 音乐模块用于管理听歌偏好、歌曲库、声乐练习、线下课程、歌曲打磨和舞台演唱能力成长。

## 模块定位

音乐不是单纯的娱乐记录，而是一个长期的兴趣资产、声乐训练系统和舞台表达能力成长模块。

创建这个模块的核心目的，是把“想唱的歌”真正唱好，并逐步靠近入门歌手水平：例如能够达到酒店驻唱歌手、Livehouse 入门歌手一类的稳定演唱与现场表达能力。

当前阶段重点围绕四件事：

1. **把一首歌唱好**：围绕目标歌曲建立选歌、拆歌、分句练习、录音复盘、舞台表达的闭环。
2. **唱歌能力提升**：记录声乐练习、歌曲练习、问题暴露和改进动作。
3. **线下课程复盘**：记录在成都本地线下机构练习时，老师反馈、课程重点、课后作业和下一次要解决的问题。
4. **听歌偏好与审美沉淀**：记录喜欢的歌、歌手、风格、情绪场景和审美变化，反向帮助选歌和表达。

## 记录原则

1. 不追求一次写完整，先把关键感受和问题记下来。
2. 听歌记录重点写“为什么喜欢”，不要只写歌名。
3. 唱歌记录重点写“暴露了什么问题”和“下一次怎么练”。
4. 每首重点歌曲都要进入歌曲练习卡片，记录从分句练习到录音复盘的过程。
5. 线下课记录必须包含：课程重点、老师反馈、课后作业、下一步行动。
6. 每月做一次音乐复盘，判断自己在审美、演唱、歌曲完成度和练习习惯上的变化。
