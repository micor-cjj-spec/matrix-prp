# 18-music / Music / 音乐与声乐成长

> 音乐模块用于管理听歌偏好、歌曲库、声乐练习、线下课程和音乐审美成长。

## 模块定位

音乐不是单纯的娱乐记录，而是一个长期的兴趣资产和表达能力训练模块。

当前阶段重点围绕三件事：

1. **听歌偏好沉淀**：记录喜欢的歌、歌手、风格、情绪场景和审美变化。
2. **唱歌能力提升**：记录声乐练习、歌曲练习、问题暴露和改进动作。
3. **线下课程复盘**：记录在成都本地线下机构练习时，老师反馈、课程重点、课后作业和下一次要解决的问题。

## 当前状态

- 偶尔会唱歌。
- 最近在成都本地找了一家线下机构练习。
- 希望通过系统记录，提高音乐视角、审美判断、演唱表达和长期进步效率。

## 核心目标

| 方向 | 目标 |
|---|---|
| 听歌 | 建立自己的音乐偏好画像，知道自己真正喜欢什么 |
| 唱歌 | 建立练习闭环，逐步提升音准、节奏、气息、咬字和表达 |
| 课程 | 每次线下课都留下可复盘记录，避免上完课就忘 |
| 审美 | 通过听歌、唱歌和复盘，提高对歌曲、声音和表达的判断力 |

## 记录原则

1. 不追求一次写完整，先把关键感受和问题记下来。
2. 听歌记录重点写“为什么喜欢”，不要只写歌名。
3. 唱歌记录重点写“暴露了什么问题”和“下一次怎么练”。
4. 线下课记录必须包含：课程重点、老师反馈、课后作业、下一步行动。
5. 每月做一次音乐复盘，判断自己在审美、演唱和练习习惯上的变化。
