# 音乐模块 Dashboard

## 当前定位

音乐模块用于记录听歌偏好、声乐练习、线下课程、歌曲打磨和舞台演唱能力成长。

当前模块的核心目的不是单纯记录喜欢的歌，而是：把想唱的歌真正唱好，并逐步靠近入门歌手、酒店驻唱歌手或 Livehouse 入门歌手的稳定演唱水平。

## 当前状态

- 喜欢听歌。
- 偶尔会唱歌。
- 最近在成都本地找了一家线下机构练习。
- 当前目标是从兴趣型唱歌，逐步过渡到“可稳定展示、可现场演唱”的入门歌手能力。

## 当前重点

| 方向 | 当前重点 | 下一步行动 |
|---|---|---|
| 目标歌曲 | 把想唱的歌从会唱推进到唱好 | 先选 1 首最想唱好的歌建立练习卡片 |
| 声乐基本功 | 建立音准、节奏、气息、咬字、共鸣和表达的训练记录 | 每次练习后记录问题和改进动作 |
| 线下课 | 把老师反馈沉淀成课后训练动作 | 每次课后当天完成课程复盘 |
| 舞台能力 | 靠近入门驻唱/Livehouse 歌手水平 | 建立阶段能力标准和展示曲目池 |
| 审美 | 从“好听”升级到“为什么好听、为什么适合我唱” | 对重点歌曲做结构、情绪、演唱分析 |

## 阶段目标

| 阶段 | 目标 | 标志 |
|---|---|---|
| 1. 会唱 | 能完整唱完目标歌曲 | 歌词熟、旋律基本顺、能跟伴奏 |
| 2. 唱稳 | 音准、节奏、气息基本稳定 | 录音听起来没有明显跑调、抢拍、断气 |
| 3. 唱好 | 有情绪层次和个人表达 | 不只是照着唱，而是能表达歌曲内容 |
| 4. 可展示 | 能在朋友/小场景中稳定唱 | 紧张时也能完成，不严重失误 |
| 5. 入门舞台 | 接近酒店驻唱/Livehouse 入门歌手能力 | 有 5-10 首稳定曲目，可连续演唱 |
