# 16-social / 社交与关系管理

## 模块定位

本模块用于记录、分析、训练和复盘我的社交能力，帮助我逐步改善人际关系、沟通表达、关系维护、社交主动性和关键关系经营能力。

它不是为了让我强行变成外向型人格，而是建立一套可执行、可复盘、可持续优化的「社交操作系统」。

## 核心目标

1. 看清楚我当前的社交状态和主要卡点
2. 建立关系地图，知道哪些关系需要维护
3. 针对常见社交场景沉淀可复用策略
4. 每次关键社交后进行复盘
5. 每周进行一次轻量总结，持续调整

## 工作流

```text
Capture → Organize → Plan → Execute → Review → Archive
记录 → 整理 → 计划 → 执行 → 复盘 → 归档
```

## 使用规则

- 不用每天记录，但重要社交一定要记录
- 先记录事实，再记录感受，避免只凭情绪判断关系
- 不追求一次变好，而是每周做一点点主动社交实验
- 对重要关系要有下一步动作，而不是等关系自然变淡
- 每周至少做一次社交复盘

## 第一阶段 MVP

接下来两周只关注三件事：

1. 建立关系地图，先列出 20 个认识的人
2. 每周主动联系 3 个人
3. 每次重要聊天后做一次简单复盘
