It uses the loopback gateway with exact Host header; no external network, redirect, production hostname, provider call, MCP endpoint, business write, data mutation, container lifecycle command or deployment. A successful result is API transport/envelope/shape evidence, not UI, business-data correctness, two-owner isolation, device UAT, or release approval.
