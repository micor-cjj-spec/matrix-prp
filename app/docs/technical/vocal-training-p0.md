# P0/P1 声乐训练中心（开发分支）

## 范围
- Web/PWA `/vocal`：4 个轻量练声任务；参考音；iOS Safari / 浏览器 MediaRecorder 录音；设备端音高估计；上传、私有播放、历史记录、删除。
- 存储：音频放在 `MATRIX_PRP_VOCAL_ROOT`（默认 `./data/vocal`），数据库只存元数据、音高摘要及 AI 文字反馈。用户最大 256MiB、单次录音 12MiB、单次最长 180 秒。
- 只有当前登录用户可以读取音频、删除录音及请求 AI 指导。音频访问必须带 JWT；返回内容不得被公共目录或 Nginx 直接暴露。
- AI 教练只发送用户备注、练习类型及设备估算摘要到当前选择的模型，**不上传原始录音**；使用现有 AI 配额。尚未实现音色、共鸣、疾病诊断、专业节奏/旋律对齐，也不应宣称听过录音。
- 无参考音的练习只显示频率与分布，不给音准分数。单音 A4 的参考音命中采用 ±50 cents 的设备粗略估算，不构成专业评估。

- 上线需完成既有正式保护门禁、数据备份、V17→V20 迁移/回滚预演与 iPhone Safari 麦克风实机验收。
- 应用启用 HTTPS 才能获得麦克风权限，首次需用户点击授权。保证 `MATRIX_PRP_VOCAL_ROOT` 位于持久化磁盘且应用账户可写，并与 MySQL 一起备份。
- 文件存在于私有服务器磁盘，非云对象存储；跨主机与多实例扩容前需要重构。上传记录若事务失败可能有孤儿文件，应定期清理。

## 验收路径
1. `node app/scripts/sync-features.mjs --check`；Vue typecheck、前端 build、后端单测和真实 MySQL Flyway CI。
2. 普通用户 A 上传、播放、查看分析；普通用户 B 猜测 A ID 的读/删/AI 均无法访问。
3. 阻止过大文件、伪装 MIME、不认识的练习码、NaN/异常样本、超时长录音及跨用户请求；删除操作只删当前用户。
4. 在 iPhone Safari、Android Chrome、桌面 Chrome 测试麦克风授权、录音格式、回放、计时停止、网络中断重试、断开麦克风后资源释放。
5. AI 密钥未配置/额度耗尽时仍可以录音和浏览记录。正式发布之前必须经过 PR 评审。
