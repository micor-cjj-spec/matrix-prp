# PRP 声乐工作台 V1

## 产品目标

让每次练习都可以被记录、关联到具体歌曲段落、复盘并转成下一次可执行的练习任务。第一阶段优先保证录音链路可靠与个人数据安全，再扩展曲目管理和课程作业。

## 已实现范围

### 1. iPhone 录音与本机预览

- 将设备端音高估算的 RMS 噪声门从 0.018 调整到 0.003，并覆盖轻声周期信号和静音回归测试。
- 在等待 iOS 麦克风权限提示前尝试恢复 AudioContext；使用浏览器默认麦克风约束；通过零增益节点维持音频分析图运行，避免把麦克风声音回放到扬声器。
- 录音结束后先生成本地 Blob，由用户试听确认后再上传。页面显示音轨状态、输入电平、文件大小和可执行的排查提示。
- 录音保存前不占用服务端存储配额；保留现有单次文件大小、用户配额、音频头校验和私有目录约束。

### 2. 个人曲库与段落

- 用户可以新增、编辑、删除曲目，并维护歌手、原调、学习状态和备注。
- 每首曲目可以建立段落，记录起止标记、练习重点和排序。
- 录音可以在录制前关联到曲目及可选段落；保存后在历史记录中展示关联。
- 删除曲目或段落不会删除原始录音；外键会将历史关联清空，避免级联删除用户录音。

### 3. 课程记录与课后作业

- 可以记录课程日期、老师/课程来源、课程内容与反馈。
- 作业可关联课程、曲目和段落，记录要求、截止日期与状态（待练习、进行中、已完成）。
- 删除课程只会解除作业的课程关联，不删除作业；删除曲目或段落只清除相关关联。
- 作业与课程列表限制返回最近 100 条课程和 200 条作业，避免不受控的全量查询。

### 4. 数据模型与隔离

新增 Flyway `V24__vocal_song_library_and_assignments.sql`，仅创建 5 张新表：

- `prp_vocal_songs`
- `prp_vocal_song_sections`
- `prp_vocal_lessons`
- `prp_vocal_assignments`
- `prp_vocal_take_links`

没有修改历史录音表结构；曲目/段落与录音的关联存放在独立链接表中。每个查询和写操作都按当前登录用户限定，服务层还会验证曲目、段落、课程、作业与录音之间的所有权和父子关系。V24 已加入受约束的新增空表迁移策略与 SQL 摘要校验。

## 技术边界

- iOS Safari 的麦克风图标只表明采集会话已启动，不能证明录到可听声音。
- RMS 电平是设备端相对幅度，不是经过校准的声压级。
- 音高仍由浏览器端估算。伴奏、多声部、气声、滑音和噪声可能导致无结果或误判。
- 当前 AI 教练仍只接收练习类型、文字备注与设备估算指标，不接收原始录音；不能声称已听过录音。
- 目前曲目库、段落、课程和作业均为用户私有数据；尚未开放老师账号、共享曲谱或跨用户协作。

## 自动化验证

- 纯音频回归测试覆盖正常音高、低音量周期信号与静音。
- `VocalLibraryDatabaseIT` 在真实 MySQL 中验证曲目/段落/课程/作业 CRUD、录音关联、跨用户访问拒绝，以及删除关联后历史录音仍存在。
- CI 运行迁移 SQL 摘要和表清单校验、真实 MySQL 迁移集成测试、后端测试、Web 类型检查与构建、移动端 H5 构建和部署保护测试。
- CI 通过不代表已完成 iPhone 实机验收。

## iPhone Safari 实机验收

1. 使用 HTTPS 登录 PRP，允许麦克风权限。
2. 选择曲目与段落，点击开始录音，轻声哼鸣 3–5 秒，确认输入电平会随声音变化。
3. 点击结束并试听，确认本机预览有声后保存；在历史记录播放上传后的录音，确认两者一致。
4. 分别测试正常音量、轻声、拒绝权限、切换应用返回和麦克风中断。
5. 验证录音关联显示正确，删除曲目/段落不会删除录音。
6. 创建一条课程记录和课后作业，关联歌曲段落，推进作业状态并确认刷新后仍保留。
7. 在 Android Chrome 和桌面 Chrome 做录音、预览、保存、播放、删除与 AI 建议回归。

## 后续阶段

### V1.2：训练会话与进度分析

- 增加一次训练会话的目标、实际完成内容、主观难度和练后感受。
- 展示同一歌曲/段落的历史录音时间线，支持同条件复练对比。
- 将课程作业与 PRP 任务中心建立可追踪的单向关联，避免重复创建与循环依赖。

### V2：服务端音频分析

- 在独立、可重试的后台任务中做客观音频 DSP 与有参考旋律时的对齐。
- 为每项结果记录算法来源、置信度、时间点与异常状态。
- 仅在所选模型明确支持音频输入时提供模型音频反馈，并与客观测量分开呈现。
