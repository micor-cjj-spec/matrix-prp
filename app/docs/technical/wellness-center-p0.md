# Matrix Health / Wellness P0

健康中心提供响应式 Web/PWA 页面（/wellness），无 uni-app 原生独立页面。包含食物库、三餐和加餐明细、营养快照、运动、身体指标、目标历史、每日汇总、14 天摄入趋势。

## 安全与权限
- 所有 /api/wellness/** 接口需 JWT；不可放入公开的 /api/health/** 探活白名单。
- 后端使用 CurrentUser.id() 获得归属，不接受前端 userId。
- 餐次/运动/体重每次访问都限定 user_id；食物为公共参考值或仅本人可见。
- 单次写入餐次与多条明细使用数据库事务，营养快照不随后续食物营养表更新而变化。
- 运动估算消耗不自动加回热量目标；没有餐次记录返回 null（未记录），不能解释为摄入零。
- 公共种子食品为近似参考值，不能当作品牌食品的精确营养成分。
- 本期不接入 AI 图像识别、自动运动计算、饮水、睡眠、原生 HealthKit。

## 部署
1. **备份**当前 matrix_prp，并核实备份可恢复。
2. 新安装先执行 002-auth.sql，再执行 007-wellness-center.sql。已存在 Docker MySQL 数据卷**必须手动执行 007**，挂载初始化目录不会自动执行升级。禁止清空数据卷。
3. 本项目仍有 PR #9 AI 和 PR #14 刷题中心分支；它们也使用 005/006 编号，合并部署时必须复核迁移顺序及版本管理。健康模块使用独立的 007 文件，不意味着部署脚本具备自动版本追踪。
4. 后端新包为 com.matrix.prp.wellness；Web 注册新 /wellness 路由，feature-registry.json 已更新。
5. 如线上使用 Nginx /prp/，前端必须以 VITE_APP_BASE=/prp/ 构建，与最新 main 的子路径部署配置一致。

## 用户流程
- 进入健康中心，设置目标（可选）；搜索公共食物或建立私人食物。
- 添加餐次，选择多个食物和克重，系统按每 100g 值计算并保存快照。
- 复制历史餐次到今天，快速重复经常吃的食物。
- 记录运动时长，运动能耗选填；记录体重、体脂率、腰围。
- 查看日汇总，14 天摄入柱图和最近 90 天的身体数据。
- 自定义食物不提供公开共享，默认只对拥有者可见。
