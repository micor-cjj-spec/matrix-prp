# Matrix PRP Roadmap

> 当前已实现的业务功能以 [自动生成的功能目录](../features/FEATURES.md) 为准；进入 main 与完成生产/实机验收是不同状态。

## 已进入 main：基础能力

- 邀请制注册、JWT 认证、用户数据隔离。
- Dashboard、记录、任务、财务、标签、复盘、知识库浏览与搜索。
- 视频课程与私有播放、存储抽象；提醒、站内消息、Web Push 基础与 iPhone 订阅诊断。
- Vue Web / uni-app H5、PWA 基础与中文化。

## P0：功能治理（本阶段）

- 唯一功能注册表、生成的前端菜单元数据、后端模块目录与功能索引。
- 构建期自动检查入口路径、模块目录及生成文件是否同步。
- 保持已有业务路由和 API 兼容。

## P1：AI 与稳定性

- DeepSeek AI 聊天功能在 PR #9，须完成实际 API、SSE 与配额验收才能合并。
- iPhone 主屏幕 PWA 推送订阅实机回归、生产部署加固、数据备份与恢复演练。
- 完善每功能测试索引、PR 变更影响分析、业务指标与运行日志。

## P2：模块深化和智能化

- Codex / OpenClaw 管理员专用受控 Worker（独立隔离、审批、配额、审计）。
- 生活、学习、工作、社交和兴趣领域功能深化。
- 应用内可搜索的功能中心、模块依赖图和自动变更影响报告。
