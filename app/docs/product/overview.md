# Product Overview

## 产品定位

Matrix PRP 是一个服务个人长期经营的多端资源管理平台，由原有 Markdown 知识库升级而来。

它不是单一的记账、待办或笔记工具，而是统一管理个人财务、社交、学习、生活、工作、兴趣和知识资产的平台。

## 核心问题

产品需要持续帮助用户回答：

- 我现在的状态是什么？
- 我接下来应该做什么？
- 我的长期趋势有没有变好？

## 核心模块

- Dashboard: 首页总览、今日状态、近期提醒、跨模块入口。
- Finance: 收入、支出、预算、账户、账单、消费复盘。
- Social: 联系人、关系地图、互动记录、沟通复盘、重要日期。
- Learning: 课程、证书、考试、学习计划、笔记和进度。
- Life: 习惯、健康、日程、购物、家务和日常记录。
- Work: 项目、会议、任务、问题记录、决策和职业成长。
- Interests: 音乐、旅行、阅读、运动、创作等兴趣成长。
- Knowledge: 浏览、搜索和利用 `knowledge/` Markdown 知识库。
- Review: 周复盘、月复盘、年度复盘和模块复盘。

## 多端定位

- Web: 深度管理、表格、图表、复盘、配置。
- Mobile: 快速记录、提醒、今日视图、轻量查看。
- CLI: 快速录入、搜索、自动化、开发者工作流。

## 产品原则

- 先形成个人使用闭环，再追求模块完整度。
- 先支持单用户，但表结构预留 `user_id` 作为未来扩展点。
- 所有模块尽量复用记录、标签、任务、复盘、附件等通用能力。
- 保留 Markdown 知识库作为长期资产，不强行一次性迁移。
