# Product Docs

这里管理 Matrix PRP 的产品定位、用户场景、模块规划、阶段范围和需求设计。

## 文档索引

- `overview.md`: 产品定位和总体设计。
- `phase-1-product-design.md`: 一期产品设计，说明目标、范围、端侧分工、模块设计和验收标准。
- `phase-1.md`: 一期范围和验收标准。
- `phase-1-requirements.md`: 一期用户故事、页面和功能需求。
- `roadmap.md`: 中长期路线图。

## 使用建议

- 新阶段开始前，先补充阶段产品设计。
- 开发过程中产生的新需求，先进入需求文档，再拆到技术、API 或数据文档。
- 已确定范围放在 `product/`，临时讨论稿可先放到 `docs/ai-notes/`。
