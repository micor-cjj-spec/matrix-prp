# Phase 1: Personal Resource Management Loop

## 目标

一期目标是把 Matrix PRP 从 Markdown 知识库推进成一个可以每天使用的个人资源管理平台雏形。

一期不追求所有模块完整，而是先完成最小闭环：

```text
登录 -> 查看状态 -> 新增记录 -> 管理任务 -> 查看财务 -> 浏览知识库
```

## 核心用户

一期默认服务单个用户，也就是项目 owner 本人。

系统设计需要保留未来多用户扩展能力，但一期不做注册、组织、团队协作和复杂权限。

## 一期产品主线

### 1. 进入系统

用户可以登录 Web 端，进入个人 Dashboard。

### 2. 看当前状态

Dashboard 汇总今日任务、最近记录、本月财务和知识库入口，让用户快速知道当前状态。

### 3. 记录发生的事

用户可以新增通用记录，例如学习、工作、生活、兴趣、社交等临时记录。

### 4. 管理要做的事

用户可以新增任务、设置截止日期、更新状态，并在 Dashboard 看到今日和近期任务。

### 5. 管理基础财务

用户可以记录收入和支出，按分类、账户、月份查看基础统计。

### 6. 使用已有知识库

用户可以在 Web 端浏览 `knowledge/` 目录树，查看 Markdown 内容。

## 一期模块范围

### 必做

- 用户登录与 JWT 鉴权
- Dashboard
- 通用记录
- 任务计划
- 财务基础
- 知识库浏览
- Web 主布局和导航
- 后端 API 文档
- MySQL 本地开发环境

### 预留

- Mobile 工程目录
- CLI 工程目录
- AI 能力入口
- 多模块扩展结构

### 不做

- 用户注册
- 多用户协作
- 完整社交关系图谱
- 完整学习课程系统
- 完整工作项目管理
- App 推送提醒
- CLI 完整功能
- AI 自动总结
- 知识库在线编辑
- 复杂权限系统

## 一期页面

Web 一期页面：

- 登录页
- Dashboard 首页
- 通用记录列表页
- 通用记录新增/编辑页
- 任务列表页
- 任务新增/编辑页
- 财务交易列表页
- 财务交易新增/编辑页
- 财务月度概览页
- 知识库目录与 Markdown 阅读页

## 一期验收标准

- 可以通过 Docker Compose 启动 MySQL。
- 后端服务可以启动并连接数据库。
- 后端接口文档可以访问。
- Web 可以登录。
- 登录后可以进入 Dashboard。
- Dashboard 可以看到今日任务、最近记录、本月财务概览和知识库入口。
- 可以新增、查看、编辑、删除通用记录。
- 可以新增、查看、编辑、完成任务。
- 可以新增收入和支出记录。
- 可以按月份查看财务收入、支出和结余。
- 可以浏览 `knowledge/` 目录树。
- 可以查看 Markdown 文件内容。

## 成功标准

一期成功不是功能数量多，而是平台已经具备日常使用价值。

如果每天能用它完成下面这些动作，就算一期成功：

- 打开 Dashboard 看今天要做什么。
- 记录一笔支出。
- 新增一条生活、学习或工作记录。
- 创建或完成一个任务。
- 查阅一份已有知识库文档。
