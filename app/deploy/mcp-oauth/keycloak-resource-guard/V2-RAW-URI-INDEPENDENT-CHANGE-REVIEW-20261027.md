> **Disposition: NO-GO / REVIEW ONLY.** This is an evidence and decision checklist, not a signed release manifest, an installation request, an approval, or a substitute for the original B2 controller. ## Requested change boundary

**Purpose:** reject noncanonical requests that Nginx would normalize into the two exact V2 MCP proxy routes. In the isolated baseline, POST `/api/%6dcp` and `/api/../api/mcp` each reached the synthetic upstream despite exact-location rules. The proposed `$request_uri` equality checks rejected these aliases while continuing to route canonical requests.

**In scope for independent *review*:** the exact pair of review-only Nginx vhosts below, with only the test vhost gaining **two** raw-URI guards. The test vhost must retain precisely two references to `127.0.0.1:18082`.

**Out of scope:** adding wildcard `/api/**` access, expanding pairing/login/grants/identity-link endpoints, altering Keycloak CIMD policies, enabling MCP writes, registering an OAuth client, updating original B2 pins or bypassing the cutover controller, and changing any production file. A broader browser pairing route package needs its own independent change decision.
