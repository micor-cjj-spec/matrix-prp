## Product
Official Grafana MCP v2.4.0 (release 2026-11-24, commit 7f717bc), Grafana 13.3.2 from #451, Prometheus and Python fixture pinned source digests from #485. Pull official versioned images, log actual digest and use immutable local image ID; image-signature verification and approved production digest are not established. https://github.com/grafana/mcp-grafana/releases/tag/v2.4.0 . Use native streamable HTTP with per-request credentials, native caller token, disabled write/API/rendering/assistant, prometheus-only categories, enforced synthetic matcher, 1h/120 point guardrail, one provisioned datasource and ephemeral Viewer. No host port, internal network and no real secrets; fixture credentials created and revoked exclusively inside this disposable runner. Native tool list and actual tool calls are checked, not inferred from annotations.

## Acceptance limits
Product probe records allowed/forbidden tool calls, foreign-label positive control and non-disclosure, missing datasource, query budget, URL/credential overrides, direct Grafana Viewer write denial, existing-session token revocation, native tool audit without credentials or query arguments, resource snapshots and exact #424/#443 security regression. Missing evidence is not PASS. Docker snapshots are short-term, not full-stack peak. The single datasource fixture is not evidence of Grafana OSS per-datasource authorization in a multi-datasource organization. The documented native PromQL guardrail ignores offset/@, and points are per series, not a strict response budget. The probe explicitly records offset behavior; even a green probe cannot establish arbitrary PromQL fixed-query policy. Raw endpoint is not an owner authorization boundary; per-user Grafana credentials are not proof of ChatGPT identity, grant, or pre-disclosure revalidation. The independent existing security regression does not integrate those controls with this product. Audit is native tool log, not a durable tamper-resistant owner access receipt. No production activation based on probe PASS.

Prefer official product plus a narrow existing #309 authorization boundary if needed, never expose unrestricted Grafana MCP directly. P4.2 only after actual results, and separate approval. Keep Draft, no merge/deploy. No new governance.
