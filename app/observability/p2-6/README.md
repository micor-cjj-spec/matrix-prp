# P2.6 offline MCP / CI-CD monitoring projection (#450)
Pure offline adapter, no network client, scheduler, token, credential, API mutation, MCP tool registration, runner, deploy or approval mechanism. GitHub Actions REST response envelopes are synthetic fixtures, not fetched live. Interactive CI lookup should continue to use the existing GitHub connector. This candidate is a Prometheus text projection / Grafana dashboard JSON, not a running exporter.

## Reuse / boundary
- #323: directly call existing dev app/scripts/release_status.py evaluate() (schema v2, unverified assertions). Never reinterpret CI success as release or LIVE. HELD remains HELD even when all CI assertions pass.
- #396: consume only the bounded *contract shape* of #456 S6.3 advisory receipt at 94e209301dfbeaf3843e2b77830229ca84410cdd: offline_simulation, BLOCKED, exact candidate commit, bounded ordered window, claimed module/cleanup statuses, false authority flags. The draft is not imported, copied or modified; no runner executed. Staging regression is not MCP runtime proof.
- #309: reuse freshness semantics from #424 snapshot_contract.py at 329ca6eb024ca3486e711fabc0ad2c428cde6221: 120s TTL, 5s future tolerance, stale/unavailable suppress current values. No import of its unmerged ops implementation and no new transport.
- MCP protocol CI is the fixed read-only list of existing MCP job groups from the CI workflow. Synthetic run success is not current endpoint availability, authorization or actual protocol health; no live MCP metric inferred. P2.1/P2.2 remain the runtime signal candidates.
- GitHub Actions REST: https://docs.github.com/en/rest/actions/workflow-runs#list-workflow-runs-for-a-repository and https://docs.github.com/en/rest/actions/workflow-jobs#list-jobs-for-a-workflow-run . Run list uses fixed repository/workflow identity, exact head SHA, run ID/attempt and total_count. Job-list pages bound to selected run/attempt; no partial or duplicate evidence accepted. No job-name, branch, URL, SHA, ID, log, body or arbitrary input exposed as labels. The caller must supply trusted metadata and correct pagination in a future integration; this offline projection does not authenticate GitHub data, verify signatures or trust the clock.
- The only workflow is CI (.github/workflows/ci.yml). Metrics count one selected attempt, not historical success rate; job duration is sum of completed job durations (not elapsed wall-clock duration). No deployment metrics claimed. Fixed labels for job states and two groups (all/mcp). Unknown/missing status remains unknown. Stale, incomplete, wrong identity or malformed input fails closed; API 429/5xx/timeout yields unavailable, subsequent complete fresh fixture recovers. No stale cache or zeros masquerading as good health.

## Tests and exclusions
Bounded page count, payload bytes, integer/UTC ranges, SHA and run/attempt linkage; reject duplicates, malformed/tampered pages and unknown state combinations, missing MCP jobs, rate limit, server failure, stale/future inputs and secret markers; confirm no side effects, no false release authority. Dashboard candidate only, no live Grafana import. No real targets, credentials, P1 changes, permission changes, governance, merge or deployment.

## Evidence limits
The #396 advisory digest is recomputed over the canonical source-domain envelope, with five module statuses, fourteen cleanup statuses and the existing 58-request outcome counts when claiming completion. This checks consistency, not authenticity. #309 freshness is applied to the envelope and each page; explicit stale/future/rate-limit/API-error/timeout/invalid states suppress prior metric values. The interactive GitHub connector currently exposes a reduced metadata shape (not the complete REST payload with timestamps, head SHA and run-attempt linkage). A future live collector must separately demonstrate those exact fields, pagination and authenticated provenance; no such collector or credentials are implemented here. CI success with skipped/neutral jobs cannot supply the release CI pass assertion in this conservative projection.
