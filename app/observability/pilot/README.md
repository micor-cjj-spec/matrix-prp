# P1.3 same-host pilot candidate — review only

No installation or production authorization. Independent monitoring project; no changes to existing PRP services or deployment controller. Docker bridge internal mode permits host/gateway access while blocking other networks: https://docs.docker.com/reference/cli/docker/network/create/#network-internal-mode---internal . Dedicated bridge, no published ports for Grafana or Prometheus, no host root or Docker socket mounts. Native Node Exporter dedicated nonroot service binds only the dedicated bridge IPv4 gateway:9100; no privileged or host-network container. Default collectors disabled; CPU, meminfo, root filesystem, netdev only. Gateway binding is not an authentication boundary: confirm host INPUT policy/routing denies other interfaces and unrelated workloads, no public reachability, dedicated network membership and no access from restricted PRP SSH identity; if not demonstrable, NO-GO. Do not edit firewall/shared Nginx/SSH policy without separate approval.

## Residual vulnerability mitigation (Grafana 13.3.2)
Trivy locations put all observed Grafana HIGH findings in the bundled PostgreSQL/Pyroscope/Jaeger/Loki/MSSQL/MySQL/OpenTSDB/Tempo datasource binaries. The candidate disables these plugin IDs, automatic preinstall, and plugin administration. CI reads the image's actual plugin.json IDs and checks authenticated /api/plugins inventory plus unchanged Prometheus queries. This reduces plugin execution exposure, not image CVE count; no finding is suppressed. Official docs: https://grafana.com/docs/grafana/latest/setup-grafana/configure-grafana/#disable_plugins . Prometheus has two HIGH dependency findings in its actual executable (x/net HTML parsing and grpc-go xDS server); the minimal candidate has no xDS service configuration and scrapes only the trusted native exporter, but actual vulnerable-symbol reachability is unproven. Residual risk needs explicit owner decision before any host pilot. No real database, extra plugins, remote write, arbitrary data sources, MCP or public access.
