## Minimal surface
One candidate tool, prp_observability_query, with exactly metric and window. Four fixed metrics: CPU busy percent, available RAM bytes, root filesystem available bytes, node scrape up. Three fixed evaluation windows 5m/15m/30m (61 evaluation points max); maximum 30m plus fixed lookback, within upstream 1h guard. Absolute UTC times derived from server clock, aligned by step, no caller time, offset, @, datasource, expression, headers, credentials or arbitrary tools. Native Grafana MCP executes fixed query against synthetic-only datasource with Viewer and write-disabled flags. Project the one allowed series into bounded numeric timestamps and values; empty data explicitly no_data, never arbitrary upstream text, hints, URLs or labels. No live tool registration.

SDK transport uses the exact #424 raw-header parser for duplicate Authorization rejection; authorization checks reuse #424 dispatch receipt with fresh introspection and grant before upstream call, after query and after durable audit before returning. Same trace ID for candidate receipt and subsequent denial if grant changes during audit; failure denies data. No audit tokens/metrics/PromQL/identity. Process-local budgets reused, not a production ingress or distributed limit.

## Acceptance and known limitations
Dedicated hosted CI uses a synthetic identity provider and patched GrantFile.current, not real OAuth or independent UID isolation; actual upstream official Grafana MCP runs in private internal Docker network, outer SDK is in-process TestClient. Existing #424/#443 regressions executed separately. P4.1 official product PASS and raw offset limitation remain; this gateway does not expose raw upstream. Existing security contract code is not yet merged. Audit is bounded local candidate receipt, not tamper-proof or network delivery proof; a race after final revalidation and before actual network delivery remains. No production hard deadline, rollback-resistant grant authority, real TLS/ingress, OAuth integration, Tunnel or full resource/peak acceptance; all require separate approval. #476/#485 independent security review and real integrated runtime remain unestablished. P1 24h pilot acceptance separate. Ordinary code review does not substitute for independent security review. Draft must remain offline-only.
