# P2.5 gateway and identity metrics candidate (#450)

Offline-only hosted CI, no production targets/config/credentials. Official NGINX OSS 1.29 Alpine and nginx-prometheus-exporter 1.4.2; Keycloak 26.8.0 native metrics with isolated dev-file H2 fixture (not actual PRP PostgreSQL/realm); P1 Prometheus 3.13.5. CI resolves image digests and runs the selected digest. No actual accounts or tokens created. NGINX public synthetic gateway exposes only fixture response and built-in disposable master realm discovery; status listener bound to its backend-network address. Keycloak management port 9000 stays on backend network, not exposed on main HTTP interface or gateway. Edge, backend and scrape networks are internal and separate. Fixed-target CI projection proxy bridges backend/scrape networks only; no caller-supplied path/query/headers to upstream, bounded body and allowlisted metric families/labels, restricted HTTP discovery route values. No actual logs, user event metrics, token/client/user/session labels or raw scrape exposed to scrape peers. NGINX access log disabled on fixture. All services unprivileged mode, no socket, no published port. Keycloak dev-mode and HTTP are disposable test conditions, not production TLS/auth approval.

Acceptance: actual NGINX stub status vs exporter counter range, generated synthetic requests; Keycloak JVM/HTTP/datasource metrics where proven; no claim of cache metrics or real OAuth/token validation. Source and projected data marker checks, management endpoints absent from public interface, scrape and edge peer direct connection denial, fixed target path/method denial, component fault/recovery plus fresh samples, resource snapshots only. NGINX stub_status has no status-code/latency histogram; do not treat it as P2.1/P2.2 replacement. No request log storage. Dashboard candidate not imported. If core tests fail, preserve NO_GO rather than relaxing isolation. P1 and all parallel work untouched. Official sources: https://github.com/nginx/nginx-prometheus-exporter/tree/v1.4.2 ; https://github.com/keycloak/keycloak/blob/26.8.0/docs/guides/server/management-interface.adoc ; https://github.com/keycloak/keycloak/blob/26.8.0/docs/guides/observability/metrics-for-troubleshooting-http.adoc .
