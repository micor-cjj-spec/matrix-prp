# 热量与饮食计划

## 当前热量目标

| 项目 | 目标 |
|---|---:|
| 每日热量范围 | 1900～2100 kcal |
| 推荐执行值 | 2000 kcal/天 |
| 蛋白质 | 120～140g/天 |
| 炒菜油 | 20～30g/天以内 |
| 主食 | 正常吃，但按量记录 |

## 餐次建议

| 餐次 | 热量建议 | 示例 |
|---|---:|---|
| 早餐 | 300～450 kcal | 2个鸡蛋 + 200ml牛奶 + 少量水果或主食 |
| 午餐 | 650～800 kcal | 瘦肉/鱼虾/鸡胸/豆腐 + 蔬菜 + 50～70g生米 |
| 晚餐 | 500～700 kcal | 高蛋白 + 多蔬菜 + 少油 + 适量主食 |

## 已讨论过的餐食估算

### 辣椒炒肉 + 米饭

食材：200g肉丝 + 200g青椒 + 70g生米饭，油偏多。

估算：

- 少油瘦肉版：650～750 kcal
- 正常炒菜版：800～900 kcal
- 油偏多/肉带肥：950～1100 kcal
- 当前记录建议：900～1000 kcal

### 番茄炒蛋 + 米饭

食材：3个鸡蛋 + 2个番茄 + 70g生米饭。

估算：650～750 kcal。

更适合长期减脂的版本：

- 2个鸡蛋 + 2个番茄 + 70g生米饭
- 估算：520～650 kcal

## 控制重点

1. 米饭不是主要问题，关键是总量和油。
2. 炒菜油需要重点控制，油一多热量会明显上升。
3. 不建议长期一天吃 5 个鸡蛋，偶尔可以，长期建议平均每天 2～3 个鸡蛋。
4. 蛋白质来源要多样化：瘦肉、鱼、虾、鸡胸、豆腐、牛奶、鸡蛋。
5. 饮食记录先追求连续，不追求绝对精确。

## 下一步行动

从明天开始，每天记录三餐食物和估算热量；连续 7 天后根据体重趋势调整热量目标。
