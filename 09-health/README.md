# 09-health

这是个人健康管理模块，用于长期记录和迭代：体重、体脂、饮食热量、运动、睡眠、皮肤状态和健康复盘。

## 模块定位

- 健康相关内容统一放在 `09-health/`。
- `04-life/` 继续用于做饭、购物、租房、日常安排等生活内容。
- 健康模块重点不是一次性完美，而是形成可持续记录、复盘、调整的闭环。

## 当前规则

凡是与以下内容相关，默认归档到本目录：

- 体重、体脂、BMI、腰围、肌肉量、内脏脂肪等级
- 饮食记录、热量估算、减脂餐、常吃食物热量
- 运动计划、步数、力量训练、有氧训练
- 睡眠、精神状态、皮肤状态
- 每日健康日志、每周复盘、阶段目标调整

## 目录结构

| 路径 | 用途 |
|---|---|
| `profile.md` | 身体基础信息、当前状态、测量规则 |
| `goals.md` | 阶段目标、体重目标、执行原则 |
| `body-data/` | 体脂秤数据、腰围、基线记录 |
| `diet/` | 热量目标、饮食原则、常吃食物热量 |
| `exercise/` | 运动计划、力量训练、有氧计划 |
| `daily-log/` | 每日饮食、体重、运动、睡眠记录 |
| `weekly-review/` | 每周健康复盘 |
| `templates/` | 日志和复盘模板 |
