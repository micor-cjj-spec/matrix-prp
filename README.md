# micro-self

这是我的个人第二大脑仓库，用于长期沉淀旅游计划、学习计划、生活计划、工作项目、财务思考、复盘记录与临时想法。

## 核心定位

- 用 Markdown 记录，保证长期可迁移、可搜索、可版本管理。
- 用 GitHub 保存，保留每一次修改历史。
- 用 ChatGPT 辅助整理、归档、复盘和迭代。
- 先保持结构清晰，不追求一次性完美。

## 目录结构

| 目录 | 用途 |
|---|---|
| `00-inbox/` | 临时收集箱，先记录，后分类 |
| `10-travel/` | 旅游计划、地点库、餐饮、住宿、复盘 |
| `20-learning/` | 学习路线、Java、AI、英语、阶段计划 |
| `30-life/` | 日常生活、做饭、购物、健康、租房 |
| `40-work/` | 工作项目、技术问题、项目笔记 |
| `50-finance/` | 预算、账户结构、财务复盘与理财思考 |
| `90-archive/` | 过期计划、历史材料、已完成内容归档 |
| `templates/` | 常用文档模板 |

## 使用规则

1. 所有正式内容优先使用 `.md` 文件。
2. 文件名建议使用 `日期 + 英文说明`，例如 `20260607-chengdu-night-walk.md`。
3. 每个模块的 `README.md` 作为该模块的目录页和使用说明。
4. 计划类文档必须包含“下一步行动”。
5. 复盘和计划分开记录，计划用于执行前，复盘用于执行后优化。

## 与 ChatGPT 协作方式

可以直接说：

- “把这次聊天整理进我的第二大脑”
- “更新成都旅游计划”
- “把这个内容归档到 learning/java 下面”
- “帮我创建一个本周学习计划”
- “总结一下最近的生活计划和待办”
