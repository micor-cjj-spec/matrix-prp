# Matrix PRP

Matrix PRP 是一个从个人知识库升级而来的长期个人资源管理项目。

当前仓库拆分为两个核心目录：

- `knowledge/`：知识库目录，保存原有的笔记、计划、模板、复盘和各资源域资料。
- `app/`：应用目录，为后续产品化和工程开发做准备。

## 使用约定

- 知识文档、资料沉淀、计划复盘、模板内容放入 `knowledge/`。
- 应用源码、工程配置、脚本工具和实现相关文档放入 `app/`。
- 根目录只保留项目级说明和仓库级配置。
