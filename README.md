# micro-self

这是我的个人第二大脑仓库，用于长期沉淀旅游计划、学习计划、生活计划、工作项目、财务思考、复盘记录与临时想法。

## 核心定位

- 用 Markdown 记录，保证长期可迁移、可搜索、可版本管理。
- 用 GitHub 保存，保留每一次修改历史。
- 用 ChatGPT 辅助整理、归档、复盘和迭代。
- 先保持结构清晰，不追求一次性完美。

## 目录结构

| 目录 | 用途 |
|---|---|
| `01-inbox/` | 临时收集箱：未经整理的想法、素材、待分类内容 |
| `02-archive/` | 归档区：过期计划、历史材料、已完成内容 |
| `03-research/` | 研究区：资料调研、信息收集、主题分析、外部资料摘要 |
| `10-travel/` | 旅游：路线、地点库、餐饮、住宿、预算、复盘 |
| `11-learning/` | 学习：Java、AI、英语、课程、阶段计划、练习记录 |
| `12-life/` | 生活：做饭、购物、健康、租房、日常计划 |
| `13-work/` | 工作：项目笔记、技术问题、需求
