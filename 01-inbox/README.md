# 01-inbox 临时收集箱

这里用于存放暂时没有分类的想法、资料、灵感和待整理内容。

## 使用原则

- 先记录，不纠结结构。
- 后续定期归档到旅游、学习、生活、工作、财务等模块。
- 不长期堆积，建议每周至少整理一次。

## 可以放什么

- 临时想法
- 突然想到的问题
- 对话中还没有整理完的内容
- 待分类资料
- 待办草稿

## 整理规则

当内容变清晰后，移动到对应模块：

- 旅游相关：`10-travel/`
- 学习相关：`11-learning/`
- 生活相关：`12-life/`
- 工作项目：`13-work/`
- 财务相关：`14-finance/`
