# 01-inbox 临时收集箱

这里用于存放暂时没有分类的想法、资料、灵感和待整理内容。

## 使用原则

- 先记录，不纠结结构。
- 后续定期归档到旅游、学习、生活、工作、财务、健康、社交、个人项目等模块。
- 不长期堆积，建议每周至少整理一次。
- 临时内容变成计划、记录或复盘后，要移动到正式模块。

## 可以放什么

- 临时想法
- 突然想到的问题
- 对话中还没有整理完的内容
- 待分类资料
- 待办草稿
- 不确定应该放到哪个模块的内容

## 整理规则

当内容变清晰后，移动到对应模块：

- 旅游相关：`10-travel/`
- 学习相关：`11-learning/`
- 生活相关：`12-life/`
- 公司工作、会议、业务项目、工作排查：`13-work/`
- 财务相关：`14-finance/`
- 健康、体重、饮食、运动、睡眠、皮肤：`15-health/`
- 社交、关系、沟通、约饭、活动复盘：`16-social/`
- 个人 GitHub 项目、个人产品、Side Project：`17-projects/`

## Work 与 Projects 快速判断

```text
公司相关 → 13-work
个人 GitHub / 个人产品 / Side Project → 17-projects
```

如果暂时判断不清楚，先留在 Inbox，并在内容里标注“待分类原因”。
