# Claude Code Outputs

> 本目录用于存放从 Claude Code 源码学习中提炼出的最终可复用结论。

## 用途

`outputs/` 目录保存可以直接支撑后续设计工作的材料，尤其是对 AI 秘书项目的参考设计。

这里不放零散笔记，只放已经整理过、可以复用、可以迁移到正式设计文档中的内容。

## 规划文件

```text
outputs/
├── README.md
├── ai-secretary-reference.md
├── orchestration-layer-design-reference.md
├── skill-layer-design-reference.md
└── safety-design-reference.md
```

## 输出标准

每份输出文档应该按“可复用设计参考”的方式写，而不是原始阅读笔记。

推荐结构：

1. 背景
2. 问题
3. Claude Code 的参考设计
4. 可以复用的部分
5. 在 AI 秘书中需要调整的部分
6. 建议实现方案
7. 风险点
8. 下一步行动
