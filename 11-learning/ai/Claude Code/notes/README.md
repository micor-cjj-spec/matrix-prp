# Claude Code Notes

> This directory stores temporary reading notes, running logs, questions, and troubleshooting records.

## Purpose

Use this directory for unstable or process-oriented materials. After notes become stable conclusions, move them into `source-summary.md`, `architecture/`, or `outputs/`.

## Suggested Files

```text
notes/
├── README.md
├── running-log.md
├── reading-notes.md
├── questions.md
└── troubleshooting.md
```

## Note Types

| Type | Description |
|---|---|
| Running log | Local clone, build, run, configuration, command records. |
| Reading notes | Temporary source reading notes before they become structured summaries. |
| Questions | Questions found during reading and later answers. |
| Troubleshooting | Build errors, runtime errors, environment issues, and solutions. |

## Writing Rule

Each note should record:

1. Date
2. Context
3. Operation or observation
4. Problem or conclusion
5. Next action
