# English 学习

英语模块用于长期维护英语学习计划、训练记录、词汇表达和阶段复盘。

## 当前目标

现阶段以 **听力 + 口语** 为主，从当前真实水平出发逐步提升，不以刷题或单纯背词为核心。

重点能力：

1. 听懂日常交流和工作场景中的高频表达。
2. 能用简单、自然、连续的英语完成日常沟通。
3. 能介绍自己的工作、项目和技术内容，并完成常见英文面试问答。
4. 逐步提升发音、语速适应、反应速度和表达准确度。

## 训练原则

- 听说优先，读写辅助。
- 先保证“能听懂、敢开口、能表达”，再追求复杂语法和高级词汇。
- 不只记录单词，也记录完整表达、使用场景和常见搭配。
- 优先沉淀自己真正会用、近期会用的表达。
- 每次训练都记录：听力问题、口语问题、纠正表达、新表达、下一步重点。
- 根据训练表现动态调整难度，不按固定教材等级硬推进。

## 目录建议

- `plan.md`：当前阶段学习路线与训练方式。
- `baseline.md`：初始水平与阶段能力评估。
- `sessions/`：每次训练记录。
- `expressions/`：高频表达、错句纠正和可复用句型。
- `review/`：周/月度复盘。
