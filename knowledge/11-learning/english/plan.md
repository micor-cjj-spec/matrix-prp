# English 听说训练计划

## 目标定位

当前训练不先假设 CEFR 等级，而是通过真实听说任务建立基线，再动态调整难度。

训练优先级：

1. 听力理解
2. 开口反应速度
3. 常用表达自然度
4. 发音与节奏
5. 语法准确度
6. 词汇扩展

## 每次训练结构（20～30 分钟）

### 1. Warm-up（3～5 分钟）

围绕当天状态、工作、生活进行简单英语对话，训练快速开口。

### 2. Listening（8～10 分钟）

使用短句、短对话或工作场景材料：

- 第一遍：只听主旨。
- 第二遍：抓关键词和细节。
- 第三遍：核对原文，分析没听出来的原因。
- Shadowing：跟读 2～5 个核心句子。

重点记录：

- 连读/弱读导致没听懂的部分
- 熟词但听不出来的部分
- 生词/新表达
- 语速适应情况

### 3. Speaking（8～10 分钟）

围绕同一主题进行输出：

- 先用自己的英语回答。
- 优先保证完整表达，不因小错误频繁中断。
- 回答后统一纠错。
- 将不自然表达改写为更常用、更口语化的表达。
- 重新说一遍改进后的版本。

### 4. Review（3～5 分钟）

每次只保留最重要的内容：

- 3～5 个高频表达
- 1～3 个主要错误
- 1 个下一次训练重点

## 阶段路线

### Phase 1：基础听说与反应（当前阶段）

目标：能够听懂慢速到正常偏慢的日常/工作英语，并用简单句连续回答。

训练主题：

- 日常生活
- 今天做了什么
- 兴趣与计划
- 自我介绍
- 工作内容
- 简单技术说明

### Phase 2：工作与技术沟通

目标：能够较自然地介绍项目、解释技术方案、回答追问。

训练主题：

- Java / Spring Boot
- MySQL / Redis
- 系统设计
- RAG / Agent
- 项目经历
- Bug 排查与技术讨论

### Phase 3：英文面试与自由交流

目标：适应正常语速问答，在没有提前准备的情况下组织 1～3 分钟回答。

训练主题：

- Behavioral interview
- Technical interview
- Project deep dive
- Follow-up questions
- Free conversation

## 难度调整规则

- 连续两次听力正确率明显偏低：降低语速或句子长度。
- 主旨容易理解但细节丢失：保持难度，加强精听。
- 能听懂但回答慢：减少新词，强化口语即时反应。
- 表达流畅但错误重复：集中训练对应语法或句型。
- 某一主题已经能够稳定表达：升级到追问、反驳和自由讨论。

## 长期维护

每次英语训练结束后，将关键结果记录到 `sessions/`；可复用表达沉淀到 `expressions/`；阶段变化更新 `baseline.md`；周期性总结写入 `review/`。
