# Claude Code Notes

> 本目录用于存放临时阅读笔记、运行记录、问题记录和排查过程。

## 用途

`notes/` 目录主要保存过程性材料和不稳定结论。等这些内容变得清晰、稳定后，再整理到 `source-summary.md`、`architecture/` 或 `outputs/` 中。

## 建议文件

```text
notes/
├── README.md
├── running-log.md
├── reading-notes.md
├── questions.md
└── troubleshooting.md
```

## 笔记类型

| 类型 | 说明 |
|---|---|
| Running log | 本地克隆、编译、运行、配置、命令记录。 |
| Reading notes | 源码阅读过程中的临时笔记，尚未整理成结构化总结。 |
| Questions | 阅读过程中产生的问题，以及后续答案。 |
| Troubleshooting | 编译错误、运行错误、环境问题和解决方案。 |

## 记录规则

每条笔记建议记录：

1. 日期
2. 背景
3. 操作或观察
4. 问题或结论
5. 下一步行动
