## 使用原则

1. 原始资料保留原件，不直接改写。
2. 从原始资料学习后产生的知识沉淀进入 `03-notes/`。
3. 刷题和错题进入 `04-questions/`。
4. 阶段总结优先沉淀为 Markdown，必要时同时保留 DOCX/PDF 版本。
