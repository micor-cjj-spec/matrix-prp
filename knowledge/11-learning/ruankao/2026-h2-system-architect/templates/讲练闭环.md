# 讲练闭环

> 四字模式名：**讲练闭环**

用于软考学习的交互式学习模式：**先讲知识点 → 出题 → 用户作答 → 逐题判定 → 记录错题与累计成绩 → 继续下一个知识点**，直到当前章节全部知识点覆盖完成。

## 一键开启提示词

```text
开启「讲练闭环」模式，按我提供的软考章节资料从头到尾学习。

规则：
1. 第一轮目标是覆盖当前章节全部知识点，不以刷熟错题为目标。
2. 每次先完整讲清一个知识点或一组强相关知识点，再基于刚讲内容出 3～5 道选择题；题量可按知识点复杂度调整。
3. 出题时绝对不要提前透露答案，不要给带答案的示例回复，也不要通过选项分布、加粗或措辞暗示正确项。
4. 我可以直接用类似 ABCBD 的连续字母作答。
5. 我作答后，逐题判断对错并解释：
   - 正确题说明为什么正确；
   - 错题说明正确答案、错误原因、易混点和记忆方法。
6. 每轮更新累计答题数、正确数、错误数和正确率。
7. 错题要记录对应知识点，但第一轮不要因为错题反复停留；先继续推进尚未覆盖的知识点。
8. 讲下一组题之前，必须先讲下一组题所对应的完整知识点。
9. 严格以当前章节资料为主，主动检查有没有遗漏的小知识点、表格项、分类、阶段、缩写、易混概念。
10. 当且仅当资料中的全部知识点都至少讲过并练过后，明确告诉我：
   “本章第一轮全部知识点已完成，可以进入下一章。”
11. 第一轮结束后，第二轮再集中进行错题回炉、变式题和易混概念混合题。
12. 如果发现前面漏讲知识点，必须补齐后才能宣布本章完成。

现在从当前章节第一个尚未覆盖的知识点开始。
```

## Skill 规则

### 目标

- 以章节为单位完成软考知识点全覆盖。
- 用“讲解 + 即时检索练习 + 反馈”的闭环方式强化理解。
- 第一轮重覆盖，第二轮重纠错，避免在单个错题上阻塞整体进度。

### 标准流程

1. **读取资料**
   - 先确认当前章节目录、页数和知识点范围。
   - 建立内部覆盖清单，避免漏项。

2. **讲知识点**
   - 每轮聚焦一个完整知识点，或一组强相关知识点。
   - 说明概念、关键词、区别、常见考法和易混点。
   - 必要时给简短记忆口诀。

3. **出题**
   - 默认 3～5 道单选题。
   - 题目优先使用场景题和辨析题，避免只考机械定义。
   - 不提前给答案，不提供含正确选项的“示例回复”。

4. **用户作答**
   - 接受 `ABCBD`、`1A 2B 3C` 等简写。
   - 若用户连续发送两次答案，以最后一次明确答案为准。

5. **判题**
   - 逐题说明：用户答案、正确/错误、正确答案、原因。
   - 错题额外指出易混概念和识别关键词。
   - 不只报总分。

6. **统计**
   - 持续维护：
     - 累计题数
     - 正确数
     - 错误数
     - 正确率
   - 被提前泄露答案或题目本身有歧义的题，不计入成绩。

7. **推进**
   - 第一轮：错题记录后继续新知识点。
   - 不因一个知识点答错就连续刷大量同类题。
   - 优先保证全章知识点覆盖。

8. **章节完成判定**
   - 对照资料再次检查覆盖清单。
   - 以下内容均不能遗漏：
     - 主干概念
     - 分类及子项
     - 阶段/流程/顺序
     - 表格中的关键对比项
     - 缩写及含义
     - 教材标出的重点
     - 容易被忽略的辅助方法或低频知识点
   - 全部覆盖后，明确宣告本章第一轮完成。

9. **第二轮**
   - 汇总第一轮错题知识点。
   - 使用变式题重新测试，不简单重复原题。
   - 增加易混概念交叉题。
   - 直到主要薄弱点闭环。

## 建议触发语

以后可直接说：

- `开启讲练闭环，学习第3章。`
- `对这份 PDF 开启讲练闭环。`
- `继续讲练闭环，从上次未覆盖的知识点开始。`
- `讲练闭环第二轮，回炉本章错题。`

## 核心原则

**先讲后练、答后反馈、持续统计、第一轮全覆盖、第二轮再纠错。**
