# 17-projects 个人项目模块

这里用于存放个人主导、长期维护、以 GitHub 仓库为主的个人项目、开源项目和 Side Project。

## 使用原则

- 只放个人项目，工作项目不要放这里。
- 每个项目可以包含：
  - `plan/` 计划
  - `log/` 记录执行过程
  - `review/` 复盘总结
  - `resources/` 资料、设计文档、源码链接
- 项目名称建议使用 GitHub 仓库名或者简短描述。
- 个人项目也可以记录目标、里程碑、功能拆分和迭代记录。

## Inbox 归档规则

- Inbox 中临时收集的个人项目内容最终归档到本模块。
- 判断规则：公司相关 → 13-work；个人 GitHub / Side Project → 17-projects。
