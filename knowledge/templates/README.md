# templates 模板库

这里存放 PRP 常用 Markdown 文档模板。

## 当前模板

| 模板 | 用途 |
|---|---|
| `travel-plan-template.md` | 旅游计划 |
| `learning-plan-template.md` | 学习计划 |
| `life-plan-template.md` | 生活计划 |
| `weekly-review-template.md` | 周复盘 |
| `prp-capture-template.md` | PRP 临时收集与归档整理 |
| `prp-module-template.md` | 新资源域模块说明模板 |

## 使用方式

创建新文档时复制模板内容，再根据具体主题修改。

建议工作流：

```text
先收集 → 再整理 → 再计划 → 执行记录 → 定期复盘 → 归档沉淀
```
