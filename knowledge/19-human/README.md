# 19-human / Human 个人成长系统

## 模块定位

本模块用于通过持续对话、状态记录、短期计划和定期复盘，帮助我更清楚地理解自己的现状，并把模糊的人生目标转化为下一步行动。

它不是一次性的性格测试，也不是追求一份看起来完美但难以执行的年度规划，而是一套可以长期更新的个人成长记录系统。

当前以 Human 3.0 的四个象限作为观察框架：

1. 心智：认知、情绪、学习、判断、执行与适应能力
2. 经济：工作、收入、职业发展、财务安全感与资源配置
3. 灵性：价值观、意义感、内在秩序、关系与生活方向
4. 身体：睡眠、饮食、运动、精力、健康状态与身体感受

> 四个象限用于帮助观察，而不是给自己贴标签。等级和评分后续逐步完善，当前先建立真实记录和行动闭环。

## 当前阶段：短期迭代

第一阶段不做一步到位的年度规划，先采用每周或关键事件后的短期循环：

```text
对话记录 → 看清现状 → 找到主要问题 → 确定一个优先目标 → 制定下一步行动 → 执行 → 复盘调整
```

每次对话重点回答三个问题：

1. 最近有什么事情完成了，或者让我感到有成就感？
2. 最近有什么事情卡住了，让我烦恼或不知道怎么继续？
3. 接下来最想优先解决的一个问题是什么？

根据回答形成一份正式记录，包括：

- 当前状态
- 已有进展
- 当前困难
- 优先目标
- 下一步行动
- 后续跟进时间
- 执行结果与调整

## 使用方式

### 1. 开始一次对话

可以直接对 ChatGPT 说：

- “开始一次 Human 对话。”
- “帮我做本周 Human 复盘。”
- “继续上一次 Human 记录。”
- “根据最近的 Human 记录，帮我调整下一步计划。”

### 2. 对话结束后写入仓库

每次有实质内容的对话，都整理成正式文档，而不是仅作为示例保存。

建议命名：

```text
records/YYYYMMDD-主题.md
```

例如：

```text
records/20260722-job-search-and-first-human-session.md
```

### 3. 下一次继续

下一次对话优先查看最近一份记录中的：

- 上次的优先目标
- 已约定的下一步行动
- 当前仍未解决的问题
- 是否出现新的变化

然后继续更新，而不是每次从零开始。

## 文件结构

| 路径 | 用途 |
|---|---|
| `README.md` | 模块定位、原则和使用方式 |
| `records/` | 每次正式对话、阶段记录和行动跟进 |
| `templates/session-template.md` | 每次对话使用的固定模板 |

## 使用原则

- 真实优先：不为了获得“好评分”而美化回答
- 行动优先：每次至少明确一个下一步行动
- 轻量优先：短期先解决最重要的问题，不一次处理所有问题
- 持续优先：允许计划调整，但要保留变化过程
- 事实与感受分开：既记录发生了什么，也记录自己的判断和感受
- 不过度诊断：本模块用于成长与复盘，不替代医疗、心理或财务专业服务

## 第一阶段目标

先连续积累真实记录，验证以下闭环是否有效：

1. 每次对话能否更快找到当前最重要的问题
2. 计划是否足够具体，第二天或本周能够执行
3. 下一次是否能基于上一次记录继续，而不是重新开始
4. 连续几周后，是否能够看出工作、状态和行动方式的变化
