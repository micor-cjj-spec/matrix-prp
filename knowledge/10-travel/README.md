# 10-travel 旅游模块

这里用于记录旅游计划、地点库、餐饮、住宿、预算、交通、复盘和避坑信息。

## 子目录

| 目录 | 用途 |
|---|---|
| `plan/` | 出行前的路线和计划 |
| `places/` | 景点、街区、公园、城市地点库 |
| `food/` | 餐饮、店铺、菜品、避坑记录 |
| `review/` | 出行后的真实复盘 |

## 记录原则

- 出行前写计划。
- 出行后写复盘。
- 好吃、好玩、踩坑都要沉淀。
- 路线要可执行，不追求一次性完美。

## 当前重点

- 成都本地轻旅游
- 牛市口附近夜间散步路线
- 低成本、轻松、适合一个人的路线
