# 初始运动计划

## 当前阶段

当前处于减脂启动期，目标是建立稳定、可持续的运动习惯。

## 每周安排

| 星期 | 内容 |
|---|---|
| 周一 | 力量训练 30～40分钟 |
| 周二 | 快走 40分钟 |
| 周三 | 力量训练 30～40分钟 |
| 周四 | 快走或骑车 40分钟 |
| 周五 | 力量训练 30～40分钟 |
| 周六 | 轻松散步 60分钟 |
| 周日 | 休息和复盘 |

## 每日基础目标

- 每天尽量 7000 步以上。
- 忙的时候至少完成 20～30 分钟散步。
- 不追求一次练很猛，优先长期稳定。

## 基础力量训练

| 动作 | 组数 |
|---|---:|
| 深蹲 | 4组 × 12次 |
| 俯卧撑，做不了就跪姿 | 4组 × 8～12次 |
| 臀桥 | 4组 × 15次 |
| 平板支撑 | 3组 × 30～60秒 |
| 卷腹或死虫 | 3组 × 12次 |

## 执行原则

1. 动作标准优先于数量。
2. 训练后不需要用暴食补偿。
3. 减脂期间力量训练的意义是保留肌肉、改善体型和提升代谢。
4. 第一周先记录完成情况，再根据疲劳程度调整动作和组数。
