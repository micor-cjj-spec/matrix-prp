# 健康目标

## 总体目标

建立一个可长期坚持的健康管理系统，围绕体重、体脂、饮食、运动和睡眠进行记录、复盘和调整。

当前核心目标：减脂、改善体型、提高日常精力。

## 阶段目标

| 阶段 | 目标体重 | 时间 | 重点 |
|---|---:|---|---|
| 第1阶段 | 85kg → 80～82kg | 8～12周 | 建立饮食记录、控制油、稳定运动 |
| 第2阶段 | 80kg → 76～78kg | 3～6个月 | 提高力量训练，减少腹部脂肪 |
| 长期维持 | 75～78kg左右 | 长期 | 不反弹，饮食正常化 |

## 减重速度

- 推荐速度：每周下降 0.4～0.8kg。
- 如果一周几乎不下降：优先检查油、零食、饮料、夜宵和实际称量误差。
- 如果一周下降超过 1kg，并且明显乏力或饥饿：适当增加主食或蛋白质。

## 每日执行目标

| 项目 | 目标 |
|---|---:|
| 总热量 | 1900～2100 kcal |
| 推荐执行值 | 2000 kcal/天 |
| 蛋白质 | 120～140g/天 |
| 炒菜油 | 20～30g/天以内 |
| 步数 | 7000步以上 |
| 力量训练 | 每周3次 |
| 复盘 | 每周1次 |

## 饮食核心原则

1. 主食不需要完全戒掉。
2. 优先控制炒菜油、肥肉、零食、饮料和夜宵。
3. 每餐尽量有蛋白质。
4. 每天保证蔬菜摄入。
5. 热量估算不追求个位数精确，先追求连续记录。

## 运动核心原则

1. 先保证可执行，不追求高强度。
2. 每天尽量多走路。
3. 每周进行 3 次基础力量训练。
4. 减脂期间力量训练的作用是保肌肉、改善体型、提升代谢。

## 复盘规则

每周复盘时重点看：

- 7日平均体重是否下降。
- 平均热量是否在目标范围内。
- 是否有高油、高糖、夜宵、饮料。
- 运动是否完成。
- 饥饿感和精神状态是否可接受。

## 下一步行动

完成明早体脂秤基线记录后，进入第一周健康记录周期。
