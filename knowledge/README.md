# PRP - Personal Resource Planning

> 个人资源计划：一个基于 Markdown、GitHub 和 ChatGPT 的个人资源管理系统。

PRP 是从“个人第二大脑”升级而来的长期系统。它不只是记录知识，而是用于管理、沉淀和优化个人资源：健康、学习、生活、工作、财务、旅行、个人项目、社交、音乐、个人成长、复盘和临时想法。

## 核心定位

PRP = Personal Resource Planning，对标 ERP（Enterprise Resource Planning，企业资源计划）。

它的目标是把个人当作一个需要长期经营的系统来管理：

- 收集信息：把临时想法、问题、计划、资料先放入系统。
- 制定计划：把模糊目标拆成可执行行动。
- 执行记录：保留过程数据，而不是只记录结论。
- 复盘优化：定期回看执行结果，调整下一步策略。
- 资产沉淀：把经验、模板、路线和决策逻辑变成长期可复用资产。

## 系统原则

- 用 Markdown 记录，保证长期可迁移、可搜索、可版本管理。
- 用 GitHub 保存，保留每一次修改历史。
- 用 ChatGPT 辅助整理、归档、复盘和迭代。
- 先形成闭环，再追求精细化。
- 所有计划都必须落到“下一步行动”。
- 复盘和计划分开记录：计划用于执行前，复盘用于执行后优化。

## Work 与 Projects 的边界

这是当前 PRP 的重要分类规则：

- `13-work/` 只放工作相关内容：公司项目、会议记录、工作任务、业务系统、工作排查、工作复盘。
- `17-projects/` 只放个人项目：个人 GitHub 仓库、开源项目、个人产品、学习型 Side Project、长期个人系统建设。
- 如果一个内容与公司任务、公司代码、公司环境、公司会议有关，即使技术上像“项目”，也归入 `13-work/`。
- 如果一个内容是自己主导、自己维护、以个人 GitHub 仓库为主的长期项目，归入 `17-projects/`。

简单判断：

```text
公司相关 → 13-work
个人 GitHub / 个人产品 / Side Project → 17-projects
```

## Human 与 Review 的边界

- `19-human/` 保存围绕个人状态、当前困难、优先目标和下一步行动形成的持续对话记录。
- `90-review/` 保存跨模块的周复盘、月复盘和阶段复盘。
- 一次 Human 对话可以聚焦一个当前问题；当积累到周或月周期后，再把变化汇总进入 `90-review/`。

## 文件命名规则

1. 所有正式内容优先使用 `.md` 文件。
2. 文件名建议使用 `日期 + 英文说明`，例如：`20260607-chengdu-night-walk.md`。
3. 每个模块的 `README.md` 作为该模块的目录页和使用说明。
4. 计划类文档必须包含“目标”“当前状态”“下一步行动”。
5. 复盘类文档必须包含“结果”“问题”“原因”“下一轮调整”。
6. 涉及账号、财务、隐私的内容只记录脱敏信息。

## PRP 工作流

```text
Capture 收集 → Organize 整理 → Plan 计划 → Execute 执行 → Review 复盘 → Archive 归档
```

### 1. Capture 收集

把聊天、想法、问题、截图、链接、待办先收进系统，不要求一开始分类完美。

### 2. Organize 整理

把收集内容归入对应资源域，例如健康、学习、旅行、财务、生活、工作、个人项目、社交、音乐、个人成长等。

### 3. Plan 计划

把目标拆成阶段、任务、时间和下一步行动。

### 4. Execute 执行

记录关键过程数据，例如体重、饮食、学习进度、工作问题、个人项目进度、旅行体验、沟通结果、声乐练习、线下课程反馈和 Human 行动跟进。

### 5. Review 复盘

按周、月、阶段回看执行结果，找到问题和下一轮改法。

### 6. Archive 归档

把过期计划、已完成内容、历史资料移动到归档区，保持当前模块清爽。

## 与 ChatGPT 协作方式

可以直接说：

- “把这次聊天整理进 PRP”
- “更新 PRP 的健康模块”
- “把这个技术问题归档到 PRP 的 learning/java 下面”
- “把这次工作组会记录到 PRP 的 work 模块”
- “把这个个人 GitHub 项目整理到 PRP 的 projects 模块”
- “把这次声乐课记录到 PRP 的 music 模块”
- “开始一次 Human 对话，并在结束后写入 PRP”
- “继续上一次 Human 记录，检查行动结果并调整计划”
- “帮我分析一下这首歌为什么好听，以及我适不适合唱”
- “帮我创建一个本周学习计划”
- “基于 PRP 总结最近一周的生活、学习、健康、社交、工作、个人项目、音乐和个人成长状态”
- “把这次复盘整理成 PRP 周复盘”
- “把这次聊天记录到 PRP 的社交模块”
