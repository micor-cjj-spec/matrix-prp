# 202606-social-expansion-plan-v1 / 成都本地社交扩展计划 V1

## 计划背景

当前社交重点从“维护旧关系”切换为“认识成都本地新朋友”。

目标不是马上交到很多朋友，而是建立一个可持续的新朋友输入系统：

```text
线上练习陌生人交流能力
线下进入成都本地活动场景
通过复见筛选可长期来往的人
```

## 核心目标

通过线下桌游局和线上 Soul 练习，建立主动认识新朋友的社交输入系统。

## 当前判断

我的主要问题不是单纯不会聊天，而是：

```text
低主动性 + 新朋友输入不足 + 聊天容易问答化 + 关系升级动作少 + 轻度社交焦虑
```

因此第一阶段不追求“立刻交朋友”，而是追求：

```text
我能主动进入新社交场景
我能和陌生人自然开口
我能完成一次低压力复见入口
```

## 总体策略

| 线路 | 方式 | 目标 |
|---|---|---|
| 线下主线 | 周末桌游局、轻松剧本杀、饭局、城市活动 | 进入真实社交场景，认识成都本地新朋友 |
| 线上副线 | Soul 陌生人聊天练习 | 训练主动开口、接话、自我表达和边界判断 |

## 线下主线：成都本地桌游/轻社交活动

### 优先渠道

- 美团
- 抖音
- 大众点评
- 小红书
- 桌游店微信群

### 优先活动类型

1. 桌游新手局
2. 阿瓦隆 / 狼人杀新手娱乐局
3. 欢乐剧本杀 / 机制本 / 轻推理本
4. 饭搭子 / 探店局
5. City Walk / 城市散步

### 第一优先级

```text
桌游新手局
```

原因：

- 游戏本身提供话题。
- 不需要一直尬聊。
- 适合新手参与。
- 容易加群和复见。
- 比纯交友局压力低。

### 暂不优先

- 深夜局
- 私人住宅局
- 强制喝酒局
- 费用不透明局
- 硬核剧本杀
- 恐怖本
- 情感沉浸本
- 强演绎本
- 大型纯陌生人交友局

## 活动筛选标准

看到一个活动后，用下面标准判断：

```text
1. 是否公开店铺
2. 是否新手友好
3. 人数是否 4-8 人优先
4. 是否晚上 10 点前结束
5. 费用是否 AA 或明码标价
6. 是否不强制喝酒
7. 是否有固定群或下次局
8. 是否明确时间、地点、人数、费用
```

最适合我的活动：

```text
成都本地 + 小规模 + 有主题 + 公开场所 + 新手友好 + 可复见
```

## 线下私信模板

### 桌游局

```text
你好，我看到你这个成都桌游局，想问一下还缺人吗？我是新手，主要想周末出来玩一下、认识点本地朋友。
```

### 剧本杀

```text
你好，我想问下这个本适合新手吗？需要强演绎吗？大概玩多久？是公开店铺拼车吗？
```

### 饭局 / 探店

```text
你好，我也在成都，最近想找周末饭搭子/探店搭子。你们这个局一般几个人、AA 吗？
```

### City Walk

```text
你好，我想参加这个周末 citywalk，想问一下大概几个人、路线和结束时间方便说一下吗？
```

## 到场话术

### 到场自我介绍

```text
我是第一次来这个局，之前玩得不多，主要想周末出来玩一下，认识点成都本地朋友。
```

### 游戏中确认规则

```text
这个规则我确认一下，是不是这样理解？
```

### 结束时留下复见入口

```text
今天挺有意思的，下次有类似新手局可以叫我。
```

### 加微信后轻联系

```text
今天一起玩挺开心的，我感觉这个局还不错。下次你们有桌游/推理局可以叫我。
```

## 线上副线：Soul 陌生人聊天练习

### 平台定位

Soul 暂时作为线上陌生人交流练习场，而不是主要找朋友渠道。

### 练习目标

- 主动开口
- 接话
- 表达自己
- 判断对方是否舒服
- 减少和陌生人聊天的紧张感

### 不追求

- 不追求马上奔现
- 不追求马上加微信
- 不追求稳定关系
- 不用一次聊天证明自己受欢迎

### 练习频率

```text
每周 3-5 次陌生人聊天
每次 5-10 分钟即可
```

### 开场模板

```text
你好，我最近想练习和陌生人自然聊天，你平时周末一般做什么？
```

```text
我最近在成都，想多认识一些本地朋友，你平时喜欢线下活动吗？
```

```text
我最近准备周末去试试桌游局，所以想练习一下和陌生人聊天。
```

## 聊天延续公式

避免只问问题，让聊天变成面试。

使用公式：

```text
问一句 + 接一句 + 说一点自己
```

例子：

```text
你平时周末也会参加这种活动吗？
我之前比较少，最近想认识一些成都本地朋友，所以开始试着参加线下局。
```

## 四周执行计划

### 第 1 周：筛选和准备

目标：筛选 3-5 个成都本地桌游/轻社交活动。

行动：

- 在美团、大众点评、抖音、小红书搜索成都桌游局。
- 记录时间、地点、人数、费用、是否新手友好。
- 在 Soul 上完成 3 次 5-10 分钟陌生人聊天练习。

### 第 2 周：第一次到场

目标：实际参加 1 次公开店铺桌游新手局。

行动：

- 完成报名或私信询问。
- 到场参与，不要求表现好。
- 至少和 2-3 个人说话。
- 结束后尝试加群或加 1 个感觉舒服的人。

### 第 3 周：第二次尝试

目标：继续参加 1 次线下活动，尝试复见或换一个活动类型。

行动：

- 如果第一次体验不错，优先复见同一家店或同一个群。
- 如果第一次体验一般，换另一个桌游局或轻松剧本杀。
- Soul 继续完成 3-5 次陌生人聊天练习。

### 第 4 周：复盘和筛选

目标：判断哪种活动最适合自己。

行动：

- 复盘线下活动体验。
- 判断是否找到可长期参加的活动场景。
- 总结最舒服的话术、最不舒服的场景、下个月继续策略。

## 风险控制

### 线下避免

- 私人住宅局
- 深夜局
- 强制喝酒局
- 费用不透明局
- 一上来交押金的局
- 明显营销、酒局、相亲销售局

### 线上避免

- 聊几句就要钱
- 诱导投资、刷单、兼职
- 强烈要求马上见面
- 要求转账、买东西、开会员
- 过度打探隐私
- 情绪勒索式聊天

## 成功标准

不要用下面标准判断成败：

```text
有没有马上交到朋友
有没有被所有人喜欢
有没有聊得特别好
```

用下面标准判断：

```text
我有没有主动进入场景
我有没有开口
我有没有比上次更自然
我有没有找到一个可以复见的地方
我有没有减少一点社交恐惧
```
